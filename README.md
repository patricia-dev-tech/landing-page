# 🥗 Landing Page - Site de Alimentação Saudável

Uma landing page responsiva desenvolvida para promover hábitos de alimentação saudável.

---

## 💻 Tecnologias Utilizadas

- *HTML5*: Estruturação semântica
- *CSS3*: Estilização, layout responsivo e Flexbox / CSS Grid

---

## 🚀 Funcionalidades

- Design responsivo (adaptado para telemóveis e computadores)
- Secção de apresentação de pratos e hábitos saudáveis
